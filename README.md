4. ПОШАГОВАЯ ИНСТРУКЦИЯ ПО ЗАПУСКУ

1) Проверить наличие Python:
python --version

Если команда python недоступна в Windows:
py --version

2) Перейти в папку проекта:
cd путь_к_папке_programming_tasks_python

3) Создать виртуальное окружение:
python -m venv .venv

4) Активировать виртуальное окружение.

PowerShell:
.\.venv\Scripts\Activate.ps1

Командная строка cmd:
.venv\Scripts\activate.bat

5) Установить зависимости:
python -m pip install -r requirements.txt

6) Запустить программы.

Задание 16.4:
python task_16_4.py

Задание 14.1:
python task_14_1.py

Задание 7.7:
python task_7_7.py

7) Запустить все автоматические тесты:
python -m pytest -v

Запуск тестов отдельного задания:
python -m pytest tests/test_task_16_4.py -v
python -m pytest tests/test_task_14_1.py -v
python -m pytest tests/test_task_7_7.py -v

5. КРАТКОЕ ОБЪЯСНЕНИЕ ПОДХОДА И АЛГОРИТМИЧЕСКАЯ СЛОЖНОСТЬ

Задание 16.4

Создан класс Time, хранящий часы, минуты и секунды. Для арифметических операций время переводится в общее количество секунд. После изменения значение преобразуется обратно в часы, минуты и секунды. Разность двух значений вычисляется как модуль разности их представлений в секундах.

Алгоритмическая сложность:
время – O(1);
дополнительная память – O(1).

Задание 14.1

Реализованы отдельные функции записи, чтения и вычисления суммы. При вычислении суммы числа считываются из файла последовательно, поэтому весь файл не требуется хранить в памяти.

Алгоритмическая сложность для n чисел:
запись – O(n);
чтение – O(n);
вычисление суммы – O(n);
дополнительная память при вычислении суммы – O(1).

Задание 7.7

Величина сдвига приводится к диапазону от 0 до n - 1 операцией k % n. Новый массив формируется из последних k элементов и первых n - k элементов исходного массива.

Алгоритмическая сложность:
время – O(n);
дополнительная память – O(n).
